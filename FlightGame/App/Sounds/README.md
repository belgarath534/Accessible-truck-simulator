# Flight Sim sounds

Recorded loops used by FlightAudio (everything else is generated live in code).

| File | What | Source | License |
|---|---|---|---|
| engine_prop.wav | Propeller engine loop | "Airplane Prop Loop" by AntumDeluge, from airplane prop noise by jakobthiesen (opengameart.org/node/132364) | CC BY 3.0 |
| wind_loop.wav | Wind (crossfaded into a loop) | "Short wind sound" by remaxim (opengameart.org/content/short-wind-sound) | CC0 |
| runway_rumble.wav | Wheels on the runway (4 to 25 s, crossfaded loop) | "Background Rumble Noise" by gryc (opengameart.org/content/background-rumble-noise) | CC BY 3.0 |

CC BY sounds are credited in the app (main menu, Credits).
